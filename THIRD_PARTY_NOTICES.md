# Чужие компоненты

Наш код (см. `NOTICE`) под MIT. Всё остальное перечислено здесь. Версии — из
`desktop/Cargo.lock` на момент 0.2.0; полный список транзитивных зависимостей
следует из того же файла.

## Системные компоненты

* **Microsoft Edge WebView2 Runtime** — проприетарное ПО Microsoft. Программа его
  использует, но не устанавливает и не распространяет: в Windows 10/11 он обычно уже есть.
* **WebKitGTK** — веб-движок для Linux, LGPL-2.1+, ставится из репозитория дистрибутива.

## Интерфейс IO

`vendor/io-web/` — сохранённая копия веб-интерфейса «IO Hub» с web.io.vision.
Она **не** под MIT: правообладатель, условия и порядок удаления описаны в
`NOTICE` и `vendor/NOTICE.md`.
