Что это

iohub-desktop — программа для настройки клавиатур IO без интернета. Внутри работает штатный интерфейс web.io.vision, а доступ к клавиатуре даёт встроенный мост HID. Программа неофициальная: интерфейс и прошивки принадлежат производителю.

Первый запуск

Нажмите Устройства → Подключить устройство и разрешите клавиатуру в появившемся списке. Разрешение запоминается в файле hid-allow.json, в следующий раз спрашивать не будет. Для новой модели достаточно разрешить её один раз — ключ устройства это VID:PID, например 05ac:024f.

Экраны

Список моделей открывается по кнопке Устройства. Когда клавиатура подключена, появляется кнопка Открыть, а в ней вкладки: Ключи, Доп. клавиши, Производительность, Подсветка, Макросы, Профили, Обслуживание. Верхняя строка с этими вкладками прокручивается вместе со схемой.

Назначить клавишу

Кликните клавишу на схеме, выберите значение в панели справа и переключите слой Base / Fn, если назначение нужно для второго слоя. Кнопка Тест показывает, какие нажатия действительно уходит с клавиатуры.

Запись в клавиатуру и прошивки

Программа пишет в память клавиатуры только то, что вы нажали сами: ни пресеты, ни фоновые процессы ничего не сохраняют. Прошивку она не меняет и не ищет сама. Список прошивок берётся из файла firmware.url в папке данных — одна строка с адресом, который вы укажете. Если файла нет, раздел прошивок остаётся пустым.

Работа без интернета

Интерфейс, картинки клавиатур и шрифты лежат внутри программы — во время работы она наружу не ходит. Кнопки GitHub и почта открываются отдельной системной командой, только когда вы сами нажимаете.

Клавиатура не появляется в списке

  • Закройте конфигуратор производителя и другие программы, которые держат устройство.
  • Попробуйте другой USB-порт и отключите переходник-хаб.
  • В Linux нужны права на /dev/hidraw* — правило udev описано в README.
  • Новую модель можно добавить вручную: строка VID:PID в hid-allow.json.

Если что-то не работает

Нажмите Сообщить об ошибке в шапке: соберётся отчёт с версией, списком устройств и последними строками журнала. Его можно сохранить в файл, отправить письмом на почту поддержки или создать задачу на GitHub. В отчёте нет ни имени пользователя, ни пути к его папке.

Где файлы

Windows — %APPDATA%\vision.io.hub.desktop, Linux — ~/.local/share/vision.io.hub.desktop. Там настройки доступа hid-allow.json, адрес прошивок firmware.url, журнал iohub-desktop.log и сохранённые отчёты в подпапке reports.

Про Linux

Сборка для Linux есть, но на реальном железе проверена меньше: там могут понадобиться права на hidraw и разбор служебного интерфейса. Это отмечено и на странице скачивания.

What this is

iohub-desktop configures IO keyboards without internet. It runs the regular web.io.vision interface and talks to the keyboard through a built-in HID bridge. The program is unofficial: the interface and the firmware belong to the manufacturer.

First run

Press Devices → Connect device and allow your keyboard in the list. The decision is remembered in hid-allow.json, so it will not ask again. A new model just needs to be allowed once — the key is VID:PID, for example 05ac:024f.

Screens

Devices opens the model list. When a keyboard is connected the Open button appears with tabs: Keys, Advanced keys, Performance, Lighting, Macros, Profiles, Maintenance.

Reassign a key

Click a key on the scheme, pick the value in the side panel and switch the Base / Fn layer if the mapping belongs to the second layer. Test keys shows what the keyboard actually sends.

Writing to the keyboard and firmware

The program writes to the keyboard only when you press the control yourself — no presets and no background process save anything. It never changes firmware on its own. The firmware list comes from the firmware.url file in the data folder: one line with the address you choose. Without that file the firmware section stays empty.

Offline

The interface, keyboard pictures and fonts are inside the program, so nothing goes out while you work. GitHub and the support email open with a separate system command, and only when you click them.

Keyboard not in the list

  • Close the manufacturer's configurator and any other program holding the device.
  • Try another USB port and drop the hub.
  • On Linux you need access to /dev/hidraw* — the udev rule is in the README.
  • A new model can be added by hand: a VID:PID line in hid-allow.json.

When something breaks

Press Report a problem in the header: the program builds a report with the version, the device list and the last log lines. Save it to a file, send it to the support email or open a GitHub issue. The report contains neither your user name nor your home folder.

Where the files are

Windows — %APPDATA%\vision.io.hub.desktop, Linux — ~/.local/share/vision.io.hub.desktop: hid-allow.json, firmware.url, iohub-desktop.log and saved reports under reports.

About Linux

Linux packages are published, but tested on real hardware less thoroughly: hidraw permissions may be needed. The download page says so as well.
