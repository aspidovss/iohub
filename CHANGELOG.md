# История изменений

Проект следует [Semantic Versioning](https://semver.org/lang/ru/); разделы — по
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## 0.2.0 — 2026-11-19

Первый публичный выпуск.

### Добавлено

* форма «Сообщить об ошибке» теперь собирает журнал программы: версия, система,
  подключённые устройства, последние строки журнала; имя пользователя из путей вычищается;
* куда деть отчёт: сохранить файлом, скопировать, письмо на `iohub@aspidov.ru`
  (штатный канал «Почта») или задача на GitHub;
* адрес списка прошивок задаётся файлом `firmware.url` в папке данных программы —
  экран «Maintenance» начинает показывать версии, как только производитель адрес укажет;
* журнал работы и подробный режим (`debug.on`), сценарии проверки интерфейса (`autotask.txt`);
* раздача доступа к устройствам автоматически только производителям из каталога
  интерфейса (0x05ac, 0x0c45, 0x3554); остальное — вручную через `hid-allow.json`;
* автосборка по тегу: установщик Windows, портативный файл, пакеты Linux (экспериментально);
* лицензии, уведомления о чужих компонентах, `SECURITY.md`, этот файл.

### Изменено

* имя программы — `iohub-desktop`, иконка — нейтральная (клавиатура без чужого знака);
* сборка под Linux описана в README и проверяется автосборкой по тегу; на живом
  железе её пока никто не запускал, поэтому пакеты помечены экспериментальными.

### Убрано

* кнопка «Старый софт» / «Legacy app» в шапке интерфейса — ссылка на внешнюю площадку
  в офлайн-программе не нужна (ключ `legacy` в конфигурации бренда обнуляется при сборке).

## 0.1.0 — 2026-11-18

Выпуск для себя, не публиковался.

### Добавлено

* офлайн-хост на Tauri 2: интерфейс клавиатурного конфигуратора встроен в файл программы,
  запросов наружу при обычной работе нет;
* собственный мост WebHID на hidapi: служебный канал клавиатуры, чтение и запись блоков
  раскладки, применение;
* права доступа по паре VID:PID — перетыкание кабеля в другой порт их не сбрасывает;
* установка (NSIS) и портативный файл; запись раскладки в память клавиатуры проверена
  с проверкой сохранности после перезапуска.
